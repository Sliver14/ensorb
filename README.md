# ensorb

A luxury, editorial wedding website & RSVP platform for **ENSORB** (Eniola & Sorbari).

## Features

- **Editorial Design System**: Bespoke aesthetic with custom palette accents (Burgundy `#6B1D2F`, Blush `#E8A598`, Mint Green `#88C4A6`, and Olive Green `#5B6B38`).
- **Interactive Sticky Navigation & Mobile Drawer**: Frosted glass backdrop blur, accessibility features, and keyboard listeners.
- **Horizontal Gift Carousel & Dedicated Registry**: Live search, price sorting, category filters, interactive gift details modal with account number copying, and cash blessings banner.
- **RSVP & Digital Ticket Pass Generator**: Guest form, photo upload, seat selector, instant barcode/QR badge generation, and 1-click printable pass.
- **Our Story & Photo Gallery**: Interactive milestone timeline and luxury photo gallery.
- **Event Details & Schedule**: Program timeline, interactive dress code swatches with 1-click HEX copier, venue logistics, and accommodation guidance.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: Next.js 16 (Turbopack) & React 19
- **Styling**: Vanilla CSS with Design System Tokens
- **Icons & Typography**: Georgia Serif, Modern sans-serif, Lucide icons
